# AgriTech Pro 🌾
> **Unified Agricultural Ecosystem: Empowering Agriculture Through Technology**

AgriTech Pro is an end-to-end, bilingual (English & Tamil) next-generation digital agriculture platform connecting all key agricultural stakeholders onto a single ecosystem: **Farmers, Wholesale Buyers, Agricultural Equipment Suppliers, Retail Grocery Sellers, Certified Agronomists, and Financial Institutions**.

---

## 🌟 Key Features

- **🌱 Smart Fertilizer Recommendation Calculator:** Precision NPK calculations, organic compost requirements, and irrigation cycles tailored to crop and soil type.
- **📊 Real-Time Mandi Price Trends & Analytics:** Live APMC mandi benchmark prices with trend charts, 24h variance, and direct fair-price indicators.
- **🚜 Farm Equipment Rental Marketplace:** On-demand rental and purchase of tractors, combine harvesters, and agricultural drone sprayers.
- **🌾 Direct Buyer-Farmer Trading:** Direct wholesale crop listings and delivery scheduling with zero middleman commissions.
- **🔬 Certified Agronomist Consultation Desk:** Pest & disease diagnosis portal connecting farmers directly with agricultural scientists.
- **💳 Kisan Credit & Crop Insurance (PMFBY):** Integrated agricultural credit options, subsidized insurance enrollment, and seasonal farm expense ledger.
- **🤖 Grounded Bilingual RAG AI Assistant:** Zero-hallucination conversational AI answering questions on government schemes, soil health, and market rates with citations.
- **🌦️ Agro-Weather & Micro-Climate Alerts:** Real-time weather warnings, rainfall probabilities, and soil moisture advisories.
- **🎨 4 Adaptive Themes & i18n:** Light, Dark, Ocean, and Neon themes with seamless English & Tamil (தமிழ்) localization.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/<your-username>/agritech.git

# Navigate into the project folder
cd agritech

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the platform.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** TypeScript, React 18
- **Styling:** Tailwind CSS, PostCSS
- **Visuals & Icons:** Lucide React, Recharts, Canvas Confetti
- **Localization:** Custom i18n Context Engine (English & Tamil)
- **AI Engine:** In-browser Grounded Retrieval-Augmented Generation (RAG) Architecture
